Connect Grill to your AI.

For people invited to Grill in chat. About two minutes. You don’t need a key, an install, or a card.

One login: sign in with the same email you signed up with, every time, in every AI. That’s how your saved decisions follow you.

Claude.ai

On the web, on Claude’s Free, Pro or Max plan. On a Team or Enterprise plan, an owner may need to allow custom connectors first.

  1. In Claude.ai, open Customize → Connectors → Add custom connector.
  2. Paste this address as the URL, name it Grill, then click Add and Connect:
    https://grillyour.ai/mcp
  3. Sign in with the same email you signed up with, every time. We email you a code. If it isn’t there in a minute, check spam.
  4. Start a new chat and type “Grill this:” followed by a decision you’re weighing. The verdict takes a minute or two.

ChatGPT

Verified working. On the web, with a paid plan.

  1. Go to Plugins, click the plus button, then Add custom MCP server.
  2. Name it Grill. Paste this address as the Server URL, and choose OAuth:
    https://grillyour.ai/mcp
  3. Click I understand and want to continue, then Create.
  4. Install it, then sign in with the same email you signed up with, every time. We email you a code. If it isn’t there in a minute, check spam.

Grok Bot

Verified working.

  1. Tell your bot: Add this MCP server: https://grillyour.ai/mcp
  2. Sign in when asked: sign in with the same email you signed up with, every time. We email you a code. If it isn’t there in a minute, check spam.

Gemini

Should work, testing now. US only, a personal Google account, and Keep Activity on.

  1. On gemini.google.com, open Settings, then Connected Apps, then Add a custom app.
  2. Paste this address, then Next:
    https://grillyour.ai/mcp
  3. If you use Gemini in the terminal, add this to ~/.gemini/settings.json: 
    {
  "mcpServers": {
    "grill": { "httpUrl": "https://grillyour.ai/mcp" }
  }
}
  4. Sign in with the same email you signed up with, every time. We email you a code. If it isn’t there in a minute, check spam.

If something goes wrong

“Grill in chat is invite-only for now.” You signed in with a different email. Disconnect Grill, connect again, and sign in with the same email you signed up with. If you have an invite code, enter it at /redeem.

No code arrived. Check spam, then ask for a new code on the sign-in screen.

Anything else: write to support@grillyour.ai. Your decisions stay private. See Privacy.
