# Contributor credit

Credit is for feedback, never decisions. Grill's privacy promise covers a person's decisions. A credit line does not.

Naming someone takes separate explicit consent for (a) being named on the site and (b) being @-tagged in a public X post. One yes does not cover the other.

## Named on the site

Being named on the site is opt-in. `data/contributors.json` records that yes in a `consent` field, and the field means nothing else. Without it, the contribute page says "suggested by a tester." The list starts empty. The owner adds a name only after that yes.

Anyone can ask to be removed at any time by emailing support@grillyour.ai. Revocation means removing them from the site within a day.

## Tagged in a public X post

Being @-tagged in a public X post needs its own explicit yes. Consent to appear on the site is not consent to be tagged. Tony approves every public post.

We can delete X posts, but we can't recall them. Someone may already have seen the post, copied it, or shared it.

## Changelog

A changelog entry may add one optional line when the person has agreed to be named on the site:

> Thanks to <name or handle>, for <the product feedback>.

Leave the line off without that consent. The line credits the feedback. It does not describe a decision.
